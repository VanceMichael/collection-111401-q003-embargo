# 场次发布源

`/schedule` 公布发布项目及 revision，release 是来源逻辑时钟的秒数，不是宿主 Unix 时间。`/time` 给出读取时的来源时间区间、时钟 epoch 和短期有效秒数；网络耗时需保留为校准不确定性，校准过期不再证明已开放。这里的 clock 可由本地控制面推进，演练无需等待墙钟。

已开放正文是 `/publication/{id}?version={排期中的版本}`。425 仍未开放，409 版本变化，410 取消。不得使用正文请求作为计时探针。generation=2 顺延 camera 并更新其正文版本，mode=cancelled 取消 sensor。开放许可只适用于对应排期版本，不能用旧排期提前领取新版本。

任务重启后，宿主单调时钟基点已经改变，保存的校准不能直接作为当前时间。

## 本地演练控制

`GET /_health` 返回服务健康状态；`GET /_audit` 仅返回请求路径、方法和体积，不记录凭据。`POST /_control` 接收 JSON，可调整 generation、mode、clock。控制端点只服务于本地演练，不是资料接口，也不是浏览器业务操作入口。每次重新启动服务都会恢复初始数据；生产接入时不部署此控制面。
